# 体細胞分裂マスター 🔬

細胞周期の流れと体細胞分裂の各時期（間期・前期・中期・後期・終期）の特徴を、図とカードを使って楽しく覚えられる学習ゲームです。

**遊ぶ**: https://tyama11.github.io/mitosis-master/

---

## 2つの学習モード

ホーム画面上部のタブから、覚えたい内容に合わせて切り替えられます。

1. **🔄 細胞周期で覚える**
   - `G₁期`・`S期`・`G₂期`・`間期`・`M期`・`分裂期`・`前期`・`中期`・`後期`・`終期` の10項目を、図の正しい位置に当てはめます。
2. **🔬 細胞スケッチで覚える**
   - 植物細胞・動物細胞の顕微鏡スケッチを見て、どの時期（`間期`・`前期`・`中期`・`後期`・`終期`）の細胞かを当てはめます。

---

## 難易度の選び方

- **🔰 かんたん**
  - 一直線の図を使って、特徴の説明を見ながらじっくり覚えられます。
- **🧪 ふつう**
  - 円の周期図で挑戦します。
  - **「ふつう」をクリアすると、秘密の「👹 おに」モードが解放されます！**（タブごとに解放）
- **👹 おに（60秒タイムアタック）**
  - 1箇所だけ空欄（`？`）になった図を見て、3択から素早く答えるモードです。
  - **ミス**: 残り時間 `-5秒`
  - **5連続正解ごと**: 残り時間 `+3秒` ボーナス
  - スコアに応じて称号（ランク S〜C）が贈られ、ホーム画面に記録されます。

---

## 操作方法

### マウス・タッチ操作
- **かんたん・ふつう**：右側のカードをクリックして選び、図の中の当てはまる枠をクリックします（カードを枠へドラッグ＆ドロップしても配置できます）。
- **おに**：3択のカードをクリックするとすぐに回答できます。
- 画面右上の **🔊 / 🔇** ボタンで効果音のオン・オフを切り替えられます。

### キーボード操作
- `Tab`：カードや図の枠へ移動
- `Enter` / `Space`：カードを選択・枠へ配置
- `Esc`：選択中のカードを解除
- `1` `2` `3`：**おにモード**で、番号に対応するカードをそのまま回答
